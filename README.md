# Biblio2935
Dans le cadre du cours IFT2935.

## Dépendances
Pour exécuter ce projet vous aurez besoin d'un serveur PostgreSQL et de Node.js (NPM).

## Pour exécuter l’application
Pour initialiser (ou réinitialiser) la base de données, exécuter `npm run init` dans votre terminal.
Ce script crée les tables et ajoute les entrées nécessaires à la démo.

Pour lancer le serveur web, exécuter `npm start`.
Si tout fonctionne, vous devriez voir l’URL du site dans la console.
Accédez à cette URL dans votre navigateur préféré et vous devriez voir l’application.
